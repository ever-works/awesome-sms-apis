## Open Source SMS Gateways

- [AwesomeSMS](https://github.com/FancyFurret/awesome-sms) - AwesomeSMS is an open-source project that allows users to text from their computer. - [Jasmin](https://github.com/jookies/jasmin) - Jasmin is a complete open source SMS Gateway written in Python with enterprise-class features including SMPP Client/Server, HTTP Client/Server, AMQP-based store-and-forward queuing, Redis-backed DLR tracking and billing, advanced message routing and filtering, Unicode support, binary SMS, and concatenated SMS.
